# CHRISCO-Bible-Quizzes

## Overview
A mobile-friendly Bible quiz platform for CHRISCO members.

## Features
- **Premium Icons**: Uses Font Awesome 6 for high-quality, professional icons.
- **Free Images**: High-quality, watermark-free images sourced from Unsplash.
- **Concept Demos**: Explains the quiz mechanics without requiring a live opponent (simulated flow).
- **Mobile Optimized Game Selection**: Users can easily pick a game mode from their mobile devices.

## How to Run
1. Open `index.html` in your browser or start a local server.
2. Select a game from the grid.
3. View the concept demos to understand the flow.

## Assets
- Icons: [Font Awesome Free](https://fontawesome.com/)
- Images: [Unsplash](https://unsplash.com/) (Free, watermark-free)
